# Jobs

Jobs finds the recruiters and companies that contacted you in Gmail, and the job threads that you started. A CronJob reads new threads every day. The web app at `https://jobs.sudhanva.me` shows the companies and recruiters in a table that you can search and sort, and lets you answer the open questions from the AI.

See `docs/src/content/docs/how-to/jobs.md` for the full guide.
