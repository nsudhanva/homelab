## What You'll Build

A self-hosted bare-metal Kubernetes cluster on node `legion` with services accessible over Tailscale via Envoy Gateway:

| Service | Hostname | Port | Purpose |
|---------|----------|------|---------|
| ArgoCD | `argocd.sudhanva.me` | 443 | GitOps control plane UI |
| Vault | `vault.sudhanva.me` | 443 | Centralized secret management |
| Grafana | `grafana.sudhanva.me` | 443 | Metrics and dashboards |
| Prometheus | `prometheus.sudhanva.me` | 443 | Metrics collection |
| Alertmanager | `alertmanager.sudhanva.me` | 443 | Alert routing |
| Headlamp | `headlamp.sudhanva.me` | 443 | Kubernetes cluster management UI |
| Home | `home.sudhanva.me` | 443 | Dashboard with service links |
| Jellyfin | `jellyfin.sudhanva.me` | 443 | Media streaming with NVIDIA GTX 1050 Ti transcoding |
| Filebrowser | `filebrowser.sudhanva.me` | 443 | File manager for persistent media volumes |
| Docs | `docs.sudhanva.me` | 443 | Cluster documentation site |

## Prerequisites

<Tabs>
  <TabItem label="Hardware">
    - Bare-metal machine (node `legion`) with Ubuntu 26.04 LTS installed
    - Minimum 4 CPU cores, 16GB RAM
    - Dedicated SSD/NVMe mounted at `/home/k3s-storage`
    - NVIDIA GeForce GTX 1050 Ti GPU for hardware acceleration
    - Stable LAN network connection and static IP
  </TabItem>
  <TabItem label="Accounts">
    - Tailscale account with Tailnet OAuth client configured for the Kubernetes operator
    - Cloudflare account with managed domain (`sudhanva.me`) and API token for ExternalDNS & cert-manager
    - GitHub personal repository with access token for ArgoCD Image Updater
  </TabItem>
  <TabItem label="Workstation">
    - macOS or Linux workstation
    - Ansible, OpenSSH, and `kubectl` installed
    - SSH key access to target node (`sudhanva@legion`) with passwordless sudo
  </TabItem>
</Tabs>

## Component Stack

| Layer | Components | Configuration Location |
|-------|------------|------------------------|
| Host & OS | Ubuntu 26.04 LTS (node `legion`) | `ansible/inventory/hosts.yaml` |
| Kubernetes | K3s `v1.36+` (`v1.36.4+k3s1`), Flannel CNI | `ansible/group_vars/all.yaml` |
| Storage | Native Local-Path Provisioner (`/home/k3s-storage`) | `ansible/roles/k3s_server/` |
| Ingress & Networking | Envoy Gateway `v1.9.1`, Tailscale Operator, ExternalDNS, CoreDNS | `infrastructure/gateway/`, `infrastructure/envoy-gateway/` |
| GitOps | ArgoCD `v3.5.2`, ApplicationSets, Image Updater | `bootstrap/`, `infrastructure/argocd-image-updater/` |
| Secrets | HashiCorp Vault `0.34.1`, External Secrets Operator `2.10.0` | `infrastructure/vault/`, `infrastructure/external-secrets/` |
| Hardware / GPU | NVIDIA GPU Operator `v26.7.0` (CDI enabled) | `infrastructure/gpu/` |
| Lifecycle | System Upgrade Controller (Plan `k3s-server`) | `infrastructure/system-upgrade-controller/` |
| Monitoring | kube-prometheus-stack, Grafana, Alertmanager, ntfy | `infrastructure/prometheus/`, `infrastructure/ntfy/` |
| Security | Kubescape Operator | `infrastructure/kubescape/` |
