## What You'll Build

You build a self-hosted bare-metal Kubernetes cluster on node `legion`. Clients connect to its services over Tailscale through Envoy Gateway:

| Service | Hostname | Port | Purpose |
|---------|----------|------|---------|
| ArgoCD | `argocd.sudhanva.me` | 443 | GitOps control plane UI |
| Vault | `vault.sudhanva.me` | 443 | Central secret management |
| Grafana | `grafana.sudhanva.me` | 443 | Metrics and dashboards |
| Prometheus | `prometheus.sudhanva.me` | 443 | Metrics collection |

## Prerequisites

<Tabs>
  <TabItem label="Hardware">
    - Bare-metal machine (node `legion`) with Ubuntu 26.04 LTS installed
    - Minimum 4 CPU cores, 16GB RAM
    - Dedicated SSD/NVMe mounted at `/home/k3s-storage`
    - NVIDIA GeForce GTX 1050 Ti GPU for hardware acceleration
    - A LAN connection (DHCP works, because K3s uses the Tailscale IP of the node)
    - Tailscale installed and joined to your tailnet
  </TabItem>
  <TabItem label="Accounts">
    - A Tailscale account with a Tailnet OAuth client for the Kubernetes operator
    - A Cloudflare account with a managed domain (`sudhanva.me`) and an API token for ExternalDNS and cert-manager
    - A GitHub repository with an access token for ArgoCD repository access and Image Updater write-back
  </TabItem>
  <TabItem label="Workstation">
    - macOS or Linux workstation
    - Ansible, OpenSSH, and `kubectl` installed
    - SSH key access to the target node (`sudhanva@legion`) with passwordless sudo
  </TabItem>
</Tabs>

## What's Included

<CardGrid stagger>
  <Card title="GitOps with ArgoCD" icon="github">
    ApplicationSets reconcile the cluster from declarative manifests. When you push a change to Git, it deploys automatically.
  </Card>
  <Card title="Ubuntu 26.04 & K3s v1.37" icon="rocket">
    Lightweight Kubernetes with Flannel CNI. Ansible provisions the node after you install Ubuntu, the NVIDIA driver, and Tailscale.
  </Card>
  <Card title="Envoy Gateway & Tailscale" icon="setting">
    Kubernetes Gateway API with the Tailscale operator, split-horizon DNS, and automatic Let's Encrypt TLS.
  </Card>
  <Card title="Vault & External Secrets" icon="approve-check">
    HashiCorp Vault keeps the secrets in one location. External Secrets Operator writes them as native Kubernetes secrets.
  </Card>
  <Card title="Local-Path SSD Storage" icon="document">
    Dynamic hostPath storage on a dedicated SSD at `/home/k3s-storage`, with no distributed storage overhead.
  </Card>
  <Card title="NVIDIA GPU Acceleration" icon="laptop">
    Hardware acceleration for the GTX 1050 Ti with the NVIDIA GPU Operator and the Container Device Interface (CDI).
  </Card>
  <Card title="Automated Upgrades" icon="seti:pipeline">
    Rancher System Upgrade Controller upgrades K3s from a `Plan` in Git. The Plan does not cordon or drain the node.
  </Card>
</CardGrid>

## Component Stack

| Layer | Components | Configuration Location |
|-------|------------|------------------------|
| Host & OS | Ubuntu 26.04 LTS (node `legion`) | `ansible/inventory/hosts.yaml` |
| Kubernetes | K3s `v1.37.1+k3s1`, Flannel CNI | `ansible/group_vars/all.yaml`, `infrastructure/system-upgrade-controller/k3s-upgrade-plan.yaml` |
| Storage | Native Local-Path Provisioner (`/home/k3s-storage`) | `ansible/roles/k3s_server/` |
| Ingress & Networking | Envoy Gateway `v1.9.2`, Tailscale Operator, ExternalDNS, CoreDNS | `infrastructure/gateway/`, `infrastructure/envoy-gateway/` |
| GitOps | ArgoCD `v3.5.6`, ApplicationSets, Image Updater | `bootstrap/`, `infrastructure/argocd-image-updater/` |
| Secrets | HashiCorp Vault chart `0.34.1`, External Secrets Operator chart `2.14.0` | `infrastructure/vault/`, `infrastructure/external-secrets/` |
| Hardware / GPU | NVIDIA GPU Operator `v26.7.2` (CDI enabled) | `infrastructure/gpu/` |
| Lifecycle | System Upgrade Controller `v0.20.2` (Plan `k3s-server`) | `infrastructure/system-upgrade-controller/` |
| Monitoring | kube-prometheus-stack, Grafana, Alertmanager | `infrastructure/prometheus/` |
| Alerting | Telegram bot (@ManassuHomelabBot) through Alertmanager and the alert-summarizer webhook | `infrastructure/prometheus/`, `apps/alert-summarizer/` |
| Security | Kubescape Operator | `infrastructure/kubescape/` |
